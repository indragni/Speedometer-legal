Speedometer
Indragni Solutions

Speedometer shows current and max speed using GPS and on-device sensors where available. Allow Location when prompted (typically “While Using the App”) for accurate speed.

Need more help? Contact options are on indragnisolutions.com. Include iOS version, device model, and whether the issue occurs indoors, in a vehicle, or walking.

Safety and legal use

  • Do not interact with the device while operating a vehicle where prohibited by law.
  • Mount the phone safely if you use it in a car; follow local hands-free rules.
  • GPS speed is approximate; never use the App as the sole instrument for safety-critical decisions.

Speed shows zero or jumps

  • Ensure Location Services are on for the App (Settings → Privacy & Security → Location Services).
  • Move to an area with a clear view of the sky; tall buildings and tunnels weaken GPS.
  • Wait a few seconds after launch for a GPS fix; first lock can be slow indoors.

Pro purchase and Restore

  • Pro is a one-time non-consumable purchase through Apple where offered.
  • Use Restore Purchases with the same Apple ID if Pro features are missing after reinstall.

Units

Switch mph, km/h, or knots in the App’s settings if available. Speed limits and signage on the road always take precedence over any in-app display.
